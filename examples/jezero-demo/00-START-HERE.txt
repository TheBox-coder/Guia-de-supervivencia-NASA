DUST RIDER - WINDING JEZERO DEMO (ENGLISH)

STEP-BY-STEP WALKTHROUGH (ABOUT 10 MINUTES)

1. START DUST RIDER
   Install Node.js 20 or later. Open a terminal in the project folder (the
   folder containing package.json), run npm start, then open
   http://localhost:8000. Keep the terminal open. If someone hosts the app,
   open their app URL instead. You still need the three JSON files below.
   Select English using the language selector in the top bar.

2. PROTECT YOUR EXISTING WORK
   Export your current mission and save your Chariot support pack before
   importing. Export any weather observations you want to keep. Demo imports
   can replace local data. Use a separate browser profile for a clean demo.
   All demo files are in examples/jezero-demo in this repository.

3. IMPORT THE MISSION
   Open Mission and use the JSON mission import action. Choose
   01-mission-five-points.json. Check that five points appear: Landing base,
   North checkpoint, South checkpoint, Delta approach and Destination.
   The base is the historical Perseverance landing-site reference in Jezero;
   the four destinations are demonstration waypoints, not historical stops.

4. IMPORT CHARIOT
   Open Chariot, choose Open pack and select 02-chariot-and-support.json.
   Read the replacement prompt before confirming. Check: crew 2, battery
   capacity 42 kWh, generator 1.2 kW, elapsed time 0 sols and a 2-sol planning
   horizon. The base and departure position should be in Jezero.
   These are demonstration inputs based partly on a conceptual dossier.

5. IMPORT WEATHER
   Open Weather and use its observations import action. Select
   03-weather-synthetic.json. Check that observations are loaded, including
   dust and radiation. There are 72 synthetic hourly records for sols
   1000-1002. These are not live measurements or NASA telemetry.

6. CALCULATE THE MISSION
   Return to Mission. Choose the shortest-distance / most-direct strategy.
   Keep Return to base OFF and Optimize order OFF. Click Calculate mission.
   Wait for terrain data to load. Open Results to inspect distance, duration
   and terrain warnings. A previous calculation gave about 9.71 km and
   6 h 18 min; this is a reference, not a guaranteed exact result.
   If calculation fails, read the detailed error and check internet access.
   Do not relax terrain limits simply to force a successful demonstration.

7. PRESENT THE MAP
   Open Map and press Fit to frame the route. Follow the five points and
   inspect the winding path. Green, yellow, orange and red describe modeled
   terrain difficulty; they do not prove that Chariot can safely drive it.
   Select MOLA to see the elevation colors and their legend. Hide Known
   locations or Landing sites if extra labels distract from the route.
   The Chariot reach circle is an ideal resource estimate, not the route
   itself or a terrain-validated area that is safe to drive.

8. EXPLORE THE 3D VIEW
   After calculation, open 3D route view from the route/results section.
   Drag the terrain to rotate it and scroll to zoom. Use Fly the route to
   start the animation, Pause to stop it and Overview to return to the
   full route. Drag the progress slider to inspect another position.
   In View settings, try Color by slope, contours, place names, vertical
   exaggeration and light direction. Orbital image is disabled when imagery
   is unavailable. Open Sources and model limits for the terrain details.
   Vertical exaggeration is visual: it does not change calculated slopes.
   On a narrow screen, scroll inside the panel to reach all settings.

9. DEMONSTRATE AN OBSERVATION UPDATE
   In Weather, first compare Mission day 1 and Mission day 2. In English,
   sol is also the scientific name for a Martian day. Index 1003 follows
   the last observed sol, 1002; it is not the first mission day's number.
   Add this synthetic astronaut observation:
     Observation sol: 1003; local hour: 12; temperature: -20 C;
     pressure: 728 Pa; wind: 4 m/s; optical depth: 3.2;
     radiation: 9.5 microSv/h; source: DEMO astronaut.
   Click Save and update prediction. Compare the projected environmental
   curves before and after saving. This refits the model; it is not a
   validated storm forecast. Re-import file 03 before repeating the same
   sol/hour, to restore the baseline observations.

10. FINISH OR RESTART
   Re-import files 01, 02 and 03 in their respective sections to restore
   the demo, then recalculate. Close the 3D panel with its X or Escape.
   To stop a local server, press Ctrl+C in its terminal.

TROUBLESHOOTING
- Empty 3D view: calculate a mission first and check elevation connectivity.
- No orbital image: terrain colors still work; imagery needs online coverage.
- Missing oxygen/battery results: follow OPTIONAL GUIDE INPUTS below and
  review the equipment confirmation; Chariot stock and suit stock differ.
- Old interface after deployment: reload after the deployment finishes.
- Import rejected: select the JSON file for that section, not this text file.
- This demo is one-way: a missing-return warning can be expected. Do not
  present this as an approved crewed mission or certified vehicle model.

ADDITIONAL REFERENCE AND OPTIONAL EXERCISES

ONLY THREE FILES TO IMPORT
1. MISSION: open 01-mission-five-points.json.
2. CHARIOT: Open pack > 02-chariot-and-support.json. This replaces the local support pack.
3. GUIDE: import 03-weather-synthetic.json as weather observations. This replaces the local weather dataset.
4. In MISSION, select Most direct / Shortest distance, Return to base OFF, Optimize order OFF. Click Calculate mission.
5. Open MAP, press Fit and let the view settle. Use Panels to hide the side panels. Optional: hide Known locations and Landing sites in Layers to keep the route readable.

WHAT TO SHOW
Five waypoints with turns: the historical Perseverance landing-site base and four demonstration destinations inside Jezero. The Chariot is moving at departure. One-way route; no automatic return. Route animation is off to keep the colored line clear. Empty shelter/relay lists avoid extra map markers.
Real elevation data produced a winding 9.71 km route in the browser, estimated 6 h 18 min. Maximum slope 15.9 degrees; minimum traversability 40/100. Terrain limits were not relaxed. Calculation requires the remote elevation service; results can change if its data change.

ROUTE COLORS
Green = Easy. Yellow = Moderate. Red = Critical. This route contains all three. Orange can also appear because the app has an additional Demanding class; it is a valid intermediate result. Colors come from the terrain-derived difficulty score, not from the dust/radiation file or the remaining 14-sol clock. A red segment is a heuristic difficulty classification, not proof that the route is safe or a certified Chariot driving limit.

CHARIOT AND WEATHER
Two crew, 42 kWh battery, proposed 1.2 kW generation; synthetic nominal demand 1.5 kW; 2-sol planning horizon; elapsed 0 sols; estimated speed 2 km/h and 4 driving hours/sol. The resource-limited reach circle is separate from route difficulty. Weather contains 72 synthetic hourly observations with dust/radiation; they are not NASA telemetry.
Optional astronaut update in WEATHER: sol 1003, local hour 12, temperature -20 C, pressure 728 Pa, wind 4 m/s, optical depth 3.2, radiation 9.5 microSv/h, observer DEMO astronaut. The environmental projections should refit. Re-import file 03 before repeating the same sol/hour.

OPTIONAL GUIDE INPUTS
Crew 2; oxygen 1.2 kg/person; declared oxygen rate 0.09 kg/h/person; battery 1.2 kWh/person; base power 0.13 kW/person; reserve 20%; departure hour 10; surface Firm; scenario Nominal. Review and confirm equipment. These suit values are synthetic and separate from Chariot stocks. A missing-return warning is expected for this one-way vehicle demonstration.

OPTIONAL CALCULATOR
Open Chariot > Open mission and emergency calculator. Use declared battery/generator data. Set one-way distance 10 km (rounded planning allowance, not the exact routed distance), speed 2 km/h, traction 0.2 kW, auxiliary 1.3 kW and reserve 20%. The calculator evaluates a separate round trip and does not add a return to the map route.
For its storm exercise: 24 h, essential load 1.8 kW, return distance 10 km, return speed 2 km/h, return traction 0.2 kW, margin 20%, generator ON. Expected required energy: 22.08 kWh. The calculator assumes a full battery and checks energy plus remaining life-policy time, not all consumables.

SOURCE AND LIMITS
Chariot V2 dossier: conceptual design targets, not certified hardware. Stocks, consumption rates, inspections and weather are synthetic. The map uses the app's real MDEM200M elevation service, with EVA-derived terrain rules rather than a validated Chariot mobility model. Start at 18.4446 N, 77.4509 E; finish at 18.4100 N, 77.3000 E.
Historical landing-site reference: https://science.nasa.gov/mission/mars-2020-perseverance/location-map/

Re-import 01/02/03 to restart. These files do not erase browser data until you import/confirm replacement.
